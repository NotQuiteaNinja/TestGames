CMDRush

Double-click Play.cmd. Python 3 is required by the small local server. No npm, Node.js, or source tree is needed.
Keep the console open while playing. Ctrl+C, then y stops the console.
You can also host this entire folder on any static web server.
Use the same browser and port to retain existing browser progress.

Feel free to do whatever you like with the app. It's almost all vibe-coded
but I wanted to make the format help individuals with ADHD gamify studying
as well as experience quicker feedback while studying. I was able to learn
about 100 Linux CLI commands in 2 days just testing the game for about an
hour and a half to two hours total. Since then I added a few more sets of
questions for SQL, Python, Regex, Windows CMD, Powershell, and I'm likely 
going to add modules for SQL Injection attacks, Python Scripting, C++,
HTML, and possibly others. Eventually, anyways.

A Chess based version with tactics puzzles, openings and lines, as well as
a collection of beginner, intermediate, and GM games to study positions
and moves from- another mode is specifically for studying punishments of
inaccurate moves and blunders. Recognizing the opportunity to take a piece
and end up on top is a valuable skill for beginners and intermediates to 
learn. The Chess version will be out soon, with a possible third version 
for memory, logic, reasoning, and mathematical skill development later on.

Even further down the road is a possible fourth version for adding your
own study material for different classes and subjects to take advantage 
of the immediate feedback for rapid memorization as well as a feature for
Automatic spaced repetition reminders to take the material from short 
term memory, encourage consolidation, then reinforce the information as
long term memory.
